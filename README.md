# FBPoints
Fantasy Baseball Points Projector \n
R Package for identifying MLB player fantasy points potential

The premise of this package is to offer a simple mechanism for calculating a Major League Baseball player's projected fantasy points for the season. The package pulls player data from razzball.com and uses ESPN's fantasy baseball rules to calculate points. The purpose of the package is to gauge players' point potential for baseball fantasy leagues. The package creates two data sets that are pulled from razzball. These datasets are updated multiple times a day throughout the season. The datasets need to be loaded before the functions can be used. These data sets are called 'pitcherData' and 'hitterData'. This player data includes all stats regarding pitching and hitting, such as runs, hits, walks, strikeouts, etc. as well as more advanced stats like ERA, OPS, and WHIP. The 'pitcherProjections()' and 'hitterProjections()' functions calculate the total fantasy points that a given player is projected to score through the course of the season. An active player name must be provided in the function and the output displays the projected points. The 'buildTeam()' function creates a dataframe that can be used as a pseudo-fantasy team builder. The purpose of the function is to create an easy to read list of potential players for a roster and includes the player name, their MLB team, their position, and their projected total points. Users can run and rerun the function and players will be added to the dataframe.
